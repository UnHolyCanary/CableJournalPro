# CableJournal Pro

## Назначение

CableJournal Pro — программа для автоматического анализа DXF/DWG проектов и формирования:

- кабельных журналов;
- спецификаций;
- ведомостей оборудования;
- анализа видеонаблюдения;
- анализа СКУД;
- анализа ОПС;
- анализа ЛВС;
- анализа оптических линий.

## Статус

🚧 В активной разработке.

## Стек

- Python 3.12
- PySide6
- ezdxf
- pandas
- openpyxl
- networkx
- shapely
